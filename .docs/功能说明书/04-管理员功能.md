# 管理员功能

## 1. 管理端入口

管理端统一入口为 `/admin`。前端路由要求：

- 用户已登录。
- 当前用户角色包含 `ADMIN`。

未登录访问管理端会跳转首页并提示登录；非管理员访问会提示无权限。

管理端菜单包括：

- 数据概览。
- 用户管理。
- 题库管理。
- 标签管理。

管理员可从登录后的用户菜单进入控制台：

![管理员用户菜单入口](assets/screenshots/admin/admin-13-admin-menu-entry.png)
*图示：管理员用户菜单入口。*

未登录访问 `/admin` 会被要求先登录：

![未登录访问管理端提示](assets/screenshots/admin/admin-11-admin-guest-denied.png)
*图示：未登录访问管理端提示。*

普通用户访问 `/admin` 会被拒绝：

![普通用户访问管理端被拒绝](assets/screenshots/admin/admin-12-admin-user-denied.png)
*图示：普通用户访问管理端被拒绝。*

管理员访问成功后进入管理控制台：

![管理员访问控制台成功](assets/screenshots/admin/admin-14-admin-console-success.png)
*图示：管理员访问控制台成功。*

## 4. 密码重置审批

普通用户提交忘记密码申请后，管理员可在用户管理中处理。

![密码重置申请区域](assets/screenshots/admin/admin-04-password-reset-requests.png)
*图示：密码重置申请区域。*

待处理申请列表：

![密码重置待处理申请](assets/screenshots/admin/admin-25-password-reset-pending-list.png)
*图示：密码重置待处理申请。*

主要能力：

- 查看待处理申请。
- 查看已批准或已拒绝申请。
- 批准密码重置。
- 拒绝密码重置。

批准后：

- 用户密码重置为默认密码 `123456`。
- 用户已有 Refresh Token 会被清理。
- 用户会被要求重新登录。

批准临时账号申请后会提示重置成功：

![批准密码重置成功提示](assets/screenshots/admin/admin-26-password-reset-approve-toast.png)
*图示：批准密码重置成功提示。*

拒绝临时账号申请后会提示已拒绝：

![拒绝密码重置成功提示](assets/screenshots/admin/admin-27-password-reset-reject-toast.png)
*图示：拒绝密码重置成功提示。*

## 8. 管理端相关接口

管理端接口与页面能力的对应关系可从用户管理、题库管理和判题环境健康检查中验证：

![管理员用户列表接口响应](assets/screenshots/api/api-08-admin-users.png)
*图示：管理员用户列表接口响应。*

![管理员题目列表接口响应](assets/screenshots/api/api-09-admin-problems.png)
*图示：管理员题目列表接口响应。*

![判题环境健康接口响应](assets/screenshots/api/api-10-judge-health.png)
*图示：判题环境健康接口响应。*

| 功能 | 接口 |
| --- | --- |
| 平台概览 | `GET /api/admin/statistics/overview` |
| 用户统计 | `GET /api/admin/statistics/users` |
| 判题环境健康 | `GET /api/admin/judge-environment/health` |
| 用户列表 | `GET /api/admin/users` |
| 用户详情 | `GET /api/admin/users/{userId}` |
| 更新用户 | `PUT /api/admin/users/{userId}` |
| 删除用户 | `DELETE /api/admin/users/{userId}` |
| 更新用户状态 | `PUT /api/admin/users/{userId}/status` |
| 密码重置申请列表 | `GET /api/admin/password-reset-requests` |
| 批准密码重置 | `POST /api/admin/password-reset-requests/{requestId}:approve` |
| 拒绝密码重置 | `POST /api/admin/password-reset-requests/{requestId}:reject` |
| 管理端题目列表 | `GET /api/admin/problems` |
| 新建题目 | `POST /api/admin/problems` |
| 题目详情 | `GET /api/admin/problems/{problemId}` |
| 更新题目 | `PUT /api/admin/problems/{problemId}` |
| 发布题目 | `POST /api/admin/problems/{problemId}:publish` |
| 归档题目 | `POST /api/admin/problems/{problemId}:archive` |
| 测试用例列表 | `GET /api/admin/problems/{problemId}/test-cases` |
| 替换测试用例 | `PUT /api/admin/problems/{problemId}/test-cases` |
| 标签列表 | `GET /api/admin/tags` |
| 新建标签 | `POST /api/admin/tags` |
| 更新标签 | `PUT /api/admin/tags/{tagId}` |
| 删除标签 | `DELETE /api/admin/tags/{tagId}` |
| 绑定题目标签 | `POST /api/admin/problems/{problemId}/tags?tagId=...` |
| 解绑题目标签 | `DELETE /api/admin/problems/{problemId}/tags?tagId=...` |
