业务状态流转图

来源：migration ENUM、entity 注释、ProblemServiceImpl、SubmissionServiceImpl、PasswordResetRequestServiceImpl。

用户状态 user.status

2待审核
→
1启用
↔
0禁用/注销

AdminController 限定 status 取值 0-2；AuthController 对待审核账号在密码校验后拦截；UserService 删除账号时将 status 置为 0。

题目状态 problem.status

DRAFT待发布
→
PUBLISHED已发布
→
ARCHIVED已归档

ProblemServiceImpl#createDraft 创建 DRAFT；publishProblem 改为 PUBLISHED；archiveProblem 改为 ARCHIVED。做题提交只允许 PUBLISHED 题目。

提交状态 submission.status

QUEUED排队
→
RUNNING判题中
→
AC通过
WA答案错误
TLE超时
MLE内存超限
RE运行错误
CE编译错误
SYSTEM_ERROR系统错误

源码和数据库实际状态为 RUNNING，不是 JUDGING；最终状态由逐用例结果归并。

密码重置状态 password_reset_request.status

PENDING待审核
→
APPROVED已批准
或
REJECTED已拒绝

PasswordResetRequestServiceImpl 只允许从 PENDING 审核为 APPROVED 或 REJECTED；审核后记录 reviewed_by、reviewed_at。
