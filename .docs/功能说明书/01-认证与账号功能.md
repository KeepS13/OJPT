# 认证与账号功能

## 1. 功能范围

认证与账号模块负责用户身份建立、登录态维护、账号状态控制和密码找回申请。前端入口主要包括顶部导航登录弹窗、注册表单、忘记密码表单、用户菜单和个人中心安全页。

## 2. 登录

用户可使用账号标识和密码登录。账号标识支持：

- 用户名。
- 邮箱。
- 手机号。

登录成功后，后端返回：

- `tokenType`，固定为 `Bearer`。
- `accessToken`，用于访问受保护接口。
- `refreshToken`，用于刷新登录态。
- `expiresIn` 和 `refreshExpiresIn`。
- 当前用户基础资料和角色信息。

前端登录成功后会把 Token 和用户资料写入登录状态，并根据角色显示普通用户入口或管理员入口。

## 4. Token 与会话维护

系统使用 JWT 和 Redis 管理登录态：

- `accessToken` 用于普通接口鉴权。
- `refreshToken` 用于刷新访问令牌。
- Refresh Token 会存入 Redis。
- 刷新 Token 时会进行令牌轮换，旧 Refresh Token 被替换。
- 如果检测到旧 Refresh Token 被重复使用，会清理该用户所有 Refresh Token。
- 退出登录会删除 Refresh Token，并将当前 Access Token 加入黑名单直到过期。

前端请求层会自动附加 `Authorization: Bearer <accessToken>`。当接口返回未授权时，前端会尝试使用 Refresh Token 换取新的访问令牌和刷新令牌，再通过当前用户接口补齐用户资料。

页面刷新或直接访问受保护路由时，前端会先执行登录态恢复流程，再进行路由权限判断，避免本地仍有 Refresh Token 但用户资料尚未加载时被误判为未登录。

## 5. 当前用户信息

登录用户可通过当前用户接口恢复会话。前端在访问个人中心或管理端等受保护路由时，如果本地存在 Token 但用户资料未加载，会先调用当前用户接口补齐用户身份。

当前用户信息包括：

- 用户 ID。
- 用户名。
- 邮箱。
- 头像。
- 角色类型。
- 账号状态。
- 角色列表。
- 创建时间和更新时间。

## 6. 账号状态

用户账号状态用于限制登录和使用：

| 状态 | 含义 | 行为 |
| --- | --- | --- |
| `0` | 禁用 | 用户不可继续正常登录或使用。 |
| `1` | 启用 | 用户可正常登录和使用。 |
| `2` | 待审核 | 密码校验通过后仍会被拦截，提示账号待审核。 |

管理员可在用户管理中修改用户状态。

## 8. 退出登录

用户主动退出登录时：

- 前端调用退出登录接口。
- 后端尝试解析当前 Access Token。
- 删除关联 Refresh Token。
- 将当前 Access Token 的 JTI 加入 Redis 黑名单。
- 前端清理本地登录状态并回到匿名状态。

## 9. 相关接口

认证接口的真实调用示例见接口响应截图：

![登录接口响应](assets/screenshots/api/api-01-login.png)
*图示：登录接口响应。*

![当前用户接口响应](assets/screenshots/api/api-03-current-user.png)
*图示：当前用户接口响应。*

| 接口 | 说明 | 访问控制 |
| --- | --- | --- |
| `POST /api/auth/login` | 登录。 | 匿名可访问 |
| `POST /api/auth/register` | 注册。 | 匿名可访问 |
| `POST /api/auth/password-reset-requests` | 提交忘记密码申请。 | 匿名可访问 |
| `POST /api/auth/refresh` | 使用 Refresh Token 换取新的访问令牌和刷新令牌，用户资料由 `/api/auth/me` 补齐。 | 匿名可访问 |
| `GET /api/auth/me` | 查询当前登录用户。 | 需要有效 Token |
| `POST /api/auth/logout` | 退出登录。 | 登录用户 |
| `GET /api/admin/password-reset-requests` | 管理员查看密码重置申请。 | `ADMIN` |
| `POST /api/admin/password-reset-requests/{requestId}:approve` | 批准密码重置申请。 | `ADMIN` |
| `POST /api/admin/password-reset-requests/{requestId}:reject` | 拒绝密码重置申请。 | `ADMIN` |
