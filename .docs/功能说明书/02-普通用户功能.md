# 普通用户功能

## 1. 首页与顶部导航

首页是 OJPT 的训练入口，面向匿名用户和登录用户开放。

主要能力：

- 展示平台名称和训练入口。
- 引导进入题库。
- 提供登录、注册入口。
- 登录后提供用户菜单、个人中心入口和提交记录入口。
- 管理员登录后显示管理后台入口。

顶部导航支持全局题目搜索。用户输入关键词后，会跳转到题库页并通过 `keyword` 查询参数触发题库筛选。

## 2. 题库列表

题库页路径为 `/problemset`，匿名用户可访问。

主要能力：

- 分页展示题目列表。
- 展示题号、题名、难度、标签、通过率、用户进度状态。
- 支持关键词搜索。
- 支持难度筛选。
- 支持用户进度状态筛选。
- 支持标签筛选。
- 支持清空关键词和清空所有筛选。
- 支持切换页码和每页数量。
- 点击题目标题或表格行进入做题页。

题号使用 `P0001` 这类格式展示，用户可按题号进入题目详情。

![题库列表](assets/screenshots/user/user-02-problemset.png)

题库支持从列表直接进入做题页，并支持分页与每页条数切换。

![从题库进入题目前的列表](assets/screenshots/user/user-21-problemset-before-open-problem.png)

![题库分页切换](assets/screenshots/user/user-23-problemset-page-switched.png)

![题库每页条数切换为 50](assets/screenshots/user/user-24-problemset-page-size-50.png)

### 2.1 顶部导航发起搜索

用户可以在任意带顶部导航的页面中输入题号、题目关键词或标签关键词，按回车后跳转到题库页。前端会把关键词写入 URL 查询参数，例如 `?keyword=P0001`，题库页读取参数后自动发起筛选。

![顶部导航输入题号搜索](assets/screenshots/user/user-09-topnav-search-input.png)

跳转到题库页后，搜索框会保留关键词，并展示匹配结果。

![按题号搜索结果](assets/screenshots/user/user-10-search-by-problem-no.png)

### 2.2 题库页关键词搜索

用户也可以直接在题库页搜索框中输入关键词。搜索采用防抖触发，输入停止后自动刷新列表，不需要额外点击搜索按钮。

示例：输入 `二分` 后，列表只展示与关键词匹配的题目。

![题库页关键词搜索](assets/screenshots/user/user-11-search-by-keyword.png)

### 2.3 难度筛选

题库页提供难度筛选，用户可以切换全部、简单、中等、困难。点击难度标签后，列表立即刷新，页码回到第一页。

![按难度筛选](assets/screenshots/user/user-12-difficulty-filter.png)

### 2.4 做题状态筛选

登录用户可以按个人做题进度筛选题目，包括全部、未开始、尝试中、已通过。该筛选用于快速定位自己尚未完成或已经通过的题目。

![按做题状态筛选](assets/screenshots/user/user-13-status-filter.png)

### 2.5 标签筛选

题库会基于当前已加载题目的标签生成标签筛选项。用户点击标签后，只展示关联该标签的题目。

![按标签筛选](assets/screenshots/user/user-14-tag-filter.png)

### 2.6 组合筛选

关键词、难度、状态和标签可以组合使用。组合筛选适合定位非常具体的题目，例如同时限定题号、简单难度、未开始状态和某个标签。

![组合筛选结果](assets/screenshots/user/user-15-combined-filters.png)

### 2.7 无结果与清空筛选

当关键词或筛选条件没有匹配题目时，页面展示空状态，并提供清空筛选入口。

![无匹配题目状态](assets/screenshots/user/user-16-empty-search.png)

点击清空筛选后，关键词、难度、状态和标签条件都会恢复默认，题库重新展示完整列表。

![清空筛选后的题库列表](assets/screenshots/user/user-17-clear-filters-result.png)

## 3. 题目详情与做题入口

做题页路径为 `/problems/:problemNo`。

页面加载内容包括：

- 题目标题。
- 题号。
- 难度。
- 时间限制。
- 内存限制。
- Markdown 题面。
- 样例测试用例。
- 标签。

匿名用户可查看题目详情，但运行、提交、草稿保存等能力需要登录。

做题和判题能力详见 `03-做题与判题功能.md`。

![点击题目后进入做题页](assets/screenshots/user/user-22-problem-solve-after-click.png)

## 4. 个人资料

个人资料页路径为 `/profile`。

主要能力：

- 查看当前用户详细资料。
- 查看头像、用户名、邮箱、手机号、角色等基础信息。
- 编辑个人资料字段，例如性别、生日、地址、网站、GitHub、公司、职位、简介等。
- 上传头像。
- 删除头像。
- 将表单重置为后端最新数据。

头像上传能力：

- 前端校验图片格式。
- 前端限制文件大小为 10MB。
- 前端压缩为 WebP 后上传。
- 后端保存头像并返回头像访问地址。

邮箱和手机号在资料页只展示，不在资料页直接修改；修改入口位于账号安全页。

## 5. 训练看板

训练看板路径为 `/profile/training`。

主要能力：

- 展示总提交数。
- 展示通过数量。
- 展示已解决题数。
- 展示通过率。
- 展示提交状态分布。
- 展示题目难度分布。
- 展示最近提交记录。

最近提交记录包含：

- 题号。
- 题名。
- 判题状态。
- 编程语言。
- 提交时间。
- 运行耗时。
- 内存占用。

## 6. 提交记录

提交记录页路径为 `/profile/submissions`。

主要能力：

- 分页查看当前用户提交历史。
- 展示题目、语言、结果、耗时、内存和提交时间。
- 查看提交代码弹窗。
- 在代码弹窗中查看源码、编译信息和判题信息。

提交记录用于回顾用户历史解题过程，也用于定位编译错误、运行错误和答案错误原因。

![提交记录](assets/screenshots/user/user-05-submissions.png)

提交记录支持分页控件操作、查看代码弹窗，并在弹窗中展示编译信息和判题信息。

## 7. 账号安全

账号安全页路径为 `/profile/security`。

主要能力：

- 查看用户名、邮箱、手机号、密码占位信息。
- 修改用户名。
- 修改邮箱。
- 修改手机号。
- 修改密码。
- 注销账号。

修改密码时，前端会校验：

- 旧密码不能为空。
- 新密码不能为空。
- 新密码和确认密码一致。
- 新密码至少 8 位。
- 新密码包含字母和数字。

注销账号需要二次确认。注销成功后，前端会清理登录状态并跳转首页。

## 8. 普通用户相关接口

普通用户页面接口与页面截图对应关系可从个人资料、训练看板和提交记录流程中验证：

![个人资料页](assets/screenshots/user/user-03-profile.png)

![训练看板](assets/screenshots/user/user-04-training-dashboard.png)

![提交记录](assets/screenshots/user/user-05-submissions.png)

| 功能 | 接口 |
| --- | --- |
| 当前用户基础信息 | `GET /api/users/me` |
| 当前用户详细信息 | `GET /api/users/me/detail` |
| 更新个人资料 | `PUT /api/users/me` |
| 上传或删除头像 | `POST /api/users/me/avatar` |
| 修改用户名 | `PUT /api/users/me/username` |
| 修改邮箱 | `PUT /api/users/me/email` |
| 修改手机号 | `PUT /api/users/me/phone` |
| 修改密码 | `PUT /api/users/me/password` |
| 注销账号 | `DELETE /api/users/me` |
| 训练看板 | `GET /api/users/me/training-dashboard` |
| 提交记录 | `GET /api/users/me/submissions` |
