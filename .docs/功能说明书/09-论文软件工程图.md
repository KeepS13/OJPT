## 4. 重新生成说明

如功能或数据模型发生变化，可重新运行：

```powershell
node .docs\功能说明书\assets\figures\paper\capture-paper-figures.js
```

脚本会读取 `paper-engineering-figures.html` 并覆盖导出同目录下的 PNG 图片。
