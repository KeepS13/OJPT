# 图表与软件工程图清单

本文档把学校和模板要求转化为 OJPT 论文可直接使用的图表规划。所有图表编号按章编排，表题置于表上方，图题置于图下方。

## 1. 图表格式总规则

插图：

1. 图号按章编号，例如 `图3-1`。
2. 图题置于图下方。
3. 图题用黑体五号，居中，单倍行距。
4. 图必须与正文说明紧密对应。
5. 图和图题不得拆到两页。
6. 图中说明尽量使用中文。

表格：

1. 表号按章编号，例如 `表4-1`。
2. 表题置于表上方。
3. 表题黑体五号，居中。
4. 表格默认三线制。
5. 表内中文宋体五号。
6. 表内英文和数字 Times New Roman 五号。
7. 空缺数据使用 `—`。

## 11. 第 6 章测试表建议

功能测试用例表字段：

| 字段 | 说明 |
| --- | --- |
| 用例编号 | 如 `TC-LOGIN-001` |
| 测试模块 | 登录、题库、做题、提交、管理端等 |
| 测试目的 | 验证功能点 |
| 输入数据 | 账号、筛选条件、代码、测试用例等 |
| 操作步骤 | 用户实际操作 |
| 期望结果 | 应出现的结果 |
| 实际结果 | 测试得到的结果 |
| 测试结论 | 通过或不通过 |

建议覆盖的测试场景：

1. 正确账号登录。
2. 错误密码登录。
3. 注册必填校验。
4. 题库关键词搜索。
5. 难度、状态、标签组合筛选。
6. 题目详情加载。
7. Tab 和 Shift+Tab 缩进。
8. Ctrl+S 手动保存草稿。
9. 新增、删除、编辑测试用例。
10. 运行代码并返回 AC。
11. 运行代码并返回错误。
12. 正式提交并轮询结果。
13. 查看提交记录。
14. 管理员新增题目。
15. 管理员维护测试用例。
16. 管理员查看判题环境健康状态。

## 12. 图表质量检查

- [ ] 图号和表号按章连续编号。

- [ ] 图题和表题没有句号。

- [ ] 图表内容与正文描述一致。
- [ ] 表格尽量使用三线表。
- [ ] 数据库表字段来自真实项目，不编造不存在字段。
- [ ] 接口清单来自真实 Controller 或功能说明书。
- [ ] 页面截图清晰，不遮挡核心内容。
- [ ] 图表不跨页断裂。
