## 4. 论文组成顺序

建议最终 Word 定稿按以下顺序组织：

1. 封面。
2. 本科毕业论文（设计）原创性声明。
3. 目录。
4. 中文题目。
5. 中文摘要与关键词。
6. 英文题目。
7. 英文摘要与关键词。
8. 正文。
9. 注释，可选。
10. 参考文献。
11. 致谢，可选，但模板和参考论文均保留。
12. 附录，可选。

## 6. 正文层级规则

自然科学类论文建议层级：

| 层级 | 示例 | 格式 |
| --- | --- | --- |
| 一级标题 | `1 绪论` | 顶格，小二号黑体 |
| 二级标题 | `1.1 研究背景` | 顶格，四号黑体 |
| 三级标题 | `1.1.1 功能需求` | 顶格，小四号黑体 |
| 四级标题 | `1.1.1.1 子项` | 顶格，小四号黑体 |
| 正文 | 段落文字 | 首行空两格，小四号宋体 |
| 条目标题 | `（1）功能名称` | 顶格，小四号黑体 |

正文排版注意：

1. 标题应简明，字数一般控制在 15 字以内。
2. 标题中一般不使用标点符号。
3. 标题不得置于页面最后一行。
4. 层级根据实际需要设置，以少为宜。
5. OJPT 论文建议控制到三级标题，四级标题仅在数据库设计、测试用例等需要精细分层时使用。

## 7. 图表与代码细则

### 7.1 表格

表格一般采用三线表：

| 线条 | 要求 |
| --- | --- |
| 上底线 | 粗实线 1 磅 |
| 下底线 | 粗实线 1 磅 |
| 中间线 | 细实线 0.75 磅 |
| 左右边线 | 一般不加 |

表格编号和内容要求：

1. 表序按章编排，如 `表3-1`。
2. 表序与表名之间空一格。
3. 表名不使用标点符号。
4. 表题置于表上方，居中排写。
5. 表头应简单明了，尽量不用斜线。
6. 全表同一单位时，将单位符号移到表头右上角并加圆括号。
7. 表中数据必须正确无误，书写清楚。
8. 表内文字和数字上下或左右相同时，不使用 `同上` 或引号代替。
9. 数据库表结构、接口清单、测试用例表均应按三线表整理。

### 7.2 插图

插图排版要求：

1. 图号按章编排，如 `图4-1`。
2. 图题由图号和图名组成。
3. 图题置于图下方。
4. 图注或其他说明置于图与图题之间。
5. 图名在图号后空一格。
6. 图题用黑体五号，居中，单倍行距。
7. 引用图应说明出处，并在图标题右上角加引用文献编号。
8. 有分图时，分图号用 `a)`、`b)` 标识并置于分图下。
9. 插图与图题是整体，不得拆到两页。
10. 相关页剩余空间不足时，可将图移到下一页最前面。

OJPT 论文应优先使用清晰的软件工程图，截图主要放在实现和测试章节，不应使用截图替代所有设计图。

### 7.3 代码

模板给出的代码格式要求：

1. 引出语可写 `该功能的核心代码如下。`
2. 代码整体首行空 2 格。
3. 单倍行距。
4. 英文和数字用 Times New Roman 五号。
5. 中文注释用宋体五号。
6. 代码前后适当空行。

论文正文不建议放大段代码。正文只展示关键逻辑片段，例如判题命令构造、JWT 校验流程、代码草稿保存逻辑；完整代码可不放或放附录。

## 8. 参考文献要求

参考文献格式：

1. 标题 `参考文献` 为小二号黑体，居中。
2. 条目中文用宋体小四，英文和数字用 Times New Roman 小四。
3. 段落行距固定值 23 磅。
4. 序号左顶格，用数字加方括号，如 `[1]`。
5. 文中引用序号格式应与参考文献一致。
6. 每条参考文献最后以句号结束。
7. 著录按 GB/T 7714-2015《信息与文献 参考文献著录规则》执行。
8. 学院模板要求至少 15 篇。
9. 学院模板要求 80% 为近 5 年文献。
10. 学院模板要求英文文献不少于 3 篇。
11. 学院模板要求不能与开题报告中的参考文献重复。

常见类型格式：

| 类型 | 格式 |
| --- | --- |
| 专著 `[M]` | `[序号] 主要作者.文献题名[M].出版地:出版社,出版年:引文页码.` |
| 学位论文 `[D]` | `[序号] 作者.文献题名[D].单位所在地:署名单位,出版年.` |
| 期刊 `[J]` | `[序号] 主要作者.文献题名[J].刊名,年,卷（期）:起止页码.` |
| 报纸 `[N]` | `[序号] 作者.新闻[N].报纸名,出版日期（版次）.` |
| 会议 `[C]` | `[序号] 主要责任者.题名:其他题名信息[C].出版地:出版社,出版年.` |
| 专利 `[P]` | `[序号] 专利申请者或所有者.专利题名:专利号[P].公告日期或公开日期.` |
| 网上期刊 `[J/OL]` | `[序号] 作者.题目[J/OL].刊名,年,卷（期）:起止页码[引用日期].网址.` |
| 电子公告 `[EB/OL]` | `[序号] 作者.题目[EB/OL].发表日期/引用日期.网址.` |

按当前写作年份 2026 计算，近 5 年文献优先选择 2021-2026 年。
