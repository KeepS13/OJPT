# 论文要求全量整理

本文档整理自 `.docs/论文要求说明/参考论文` 下的学校规范、学院模板和参考论文样例。执行优先级为：学校《本科毕业论文（设计）规范化要求》高于学院模板，学院模板高于参考论文样例。参考论文只用于观察章节组织、图表密度和软件工程写法，不作为硬性格式来源。

## 1. 论文组成

本科毕业论文（设计）应包括以下部分：

1. 封面。
2. 本科毕业论文（设计）原创性声明。
3. 目录。
4. 中文题目。
5. 中文摘要与关键词。
6. 英文题目。
7. 英文摘要与关键词。
8. 正文。
9. 注释，可选。
10. 参考文献。
11. 致谢，可选，但学院模板和参考论文均保留。
12. 附录，可选。

推荐 OJPT 论文采用完整结构：封面、原创性声明、目录、摘要、Abstract、正文 1-7 章、参考文献、致谢。附录仅在需要放大段代码、补充接口清单或测试记录时使用。

## 3. 封面与原创性声明

封面字段包括：

| 字段 | 写法 |
| --- | --- |
| 归档号 | `归 档 号：...`，模板提示为黑体小三 |
| 学院 | 计算机与自动化学院 |
| 专业 | 软件工程 |
| 年级 | 2022 级 |
| 学生 | 学生姓名 |
| 学号 | 学号 |
| 指导教师 | 指导教师姓名 |
| 职称 | 指导教师职称 |
| 题目 | 论文中文题目 |
| 日期 | `2026年 月 日` |

封面标题 `武汉工商学院毕业论文(设计)`：模板要求宋体一号、加粗、居中。封面表格字段：模板要求宋体小三加粗。

原创性声明要求放在封面后、目录前。声明标题 `武汉工商学院 本科毕业论文（设计）原创性声明`，模板要求宋体二号加粗、居中、单倍行距。声明正文宋体四号、单倍行距、首行缩进 2 字符。末尾保留作者签名和日期。

## 4. 目录

目录独立成页，应包含：

1. 摘要与关键词。
2. Abstract 与 Key words。
3. 正文二级标题，也可包含三级标题。
4. 参考文献。
5. 致谢。
6. 附录，如有。

目录格式：

| 项目 | 要求 |
| --- | --- |
| 目录题头 | `目 录`，小二号黑体，居中，两字之间空一格 |
| 中文字体 | 小四号宋体 |
| 英文字体 | 小四号 Times New Roman |
| 行距 | 固定值 23 磅 |
| 一级标题缩进 | 无缩进 |
| 二级标题缩进 | 2 字符 |
| 三级标题缩进 | 4 字符 |

目录页不编页码，但目录中应显示目录后各部分的实际页码。最终 Word 定稿应使用 Word 自动目录或手动核对页码。

## 5. 题目

题目要求：

1. 中文题目一般不超过 20 个字。
2. 外文题目不超过 15 个实词。
3. 题目简洁明了、有概括性。
4. 中英文题名应一致。
5. 标题中尽量不用英文缩写词；必须使用时，应采用本行业通用缩写。
6. 可使用副标题。
7. 标题一般不使用标点符号。

OJPT 推荐中文题目为：`基于 Spring Boot 的在线编程训练平台设计与实现`。该题目略超过 20 字风险边界，正式提交前可压缩为 `基于SpringBoot的在线编程训练平台设计与实现` 或按导师意见调整。

## 6. 摘要与关键词

摘要要求：

1. 中文摘要和英文摘要单独成页，置于目录后，中文在前，英文在后。
2. 摘要是对论文内容不加注释和评论的简短陈述。
3. 应说明研究工作的目的、主要内容和方法、研究结果、结论、科学意义或应用价值。
4. 摘要应具有独立性和完整性。
5. 摘要中不宜使用公式、图表、非公知公用的符号和术语。
6. 摘要中不标注引用文献编号。

摘要格式：

| 项目 | 中文要求 | 英文要求 |
| --- | --- | --- |
| 标题 | `摘  要`，小二号黑体居中 | `Abstract`，Times New Roman 小二加粗居中 |
| 内容 | 小四号宋体，固定 23 磅 | Times New Roman 小四，固定 23 磅 |
| 关键词标签 | 黑体小四 | Times New Roman 小四加粗 |
| 关键词内容 | 小四号宋体 | Times New Roman 小四 |

关键词要求：

1. 一般列 3-5 个。
2. 采用能覆盖论文主要内容的通用技术词条。
3. 按词条外延层次从大到小排列。
4. 中英文关键词一一对应。
5. 中文关键词之间用分号 `；` 分隔。

OJPT 推荐关键词方向：在线判题；Spring Boot；Vue；Docker；代码评测。正式写作时可根据题目调整。

## 7. 正文结构与标题层级

正文应体系完整、结构合理、内容与标题一致。正文部分包括绪论、论文主体和结论。绪论可说明选题目的和意义、国内外文献综述、研究内容。主体应观点明确、重点突出、条理清晰、层次分明。结论应简练总结所做工作。

自然科学类论文层级格式：

| 层级 | 代号示例 | 格式 |
| --- | --- | --- |
| 一级标题 | `1 绪论` | 顶格，小二号黑体 |
| 二级标题 | `1.1 研究背景` | 顶格，四号黑体 |
| 三级标题 | `1.1.1 功能需求` | 顶格，小四号黑体 |
| 四级标题 | `1.1.1.1 子项` | 顶格，小四号黑体 |
| 正文 | 段落文字 | 首行空两格，小四号宋体 |
| 条目标题 | `（1）功能名称` | 顶格，小四号黑体 |

正文其他要求：

1. 正文除标题外均用小四号宋体。
2. 各级标题应突出重点、简明扼要，字数一般在 15 字以内。
3. 标题中不使用标点符号。
4. 标题不得置于页面最后一行。
5. 层次根据实际需要设置，以少为宜。
6. 学院模板强调每章独立分页。

OJPT 论文建议控制到三级标题，四级标题仅在数据库设计、测试用例等需要精细分层时使用。

## 8. 注释

注释为可选项，用于解释特定名词、新名词，或对引用观点、原话、主要数据注明出处。

注释要求：

1. 采用页末注，不用行中注。
2. 按出现先后顺序编号。
3. 正文中的注释号用圆圈数字右上角标注，如 `①`。
4. 页面下方脚注中文为五号宋体，数字和字母为五号 Times New Roman。
5. 注释序号左顶格，并用圆圈数字表示。

OJPT 论文如无特殊名词解释，可不设置注释，避免增加格式复杂度。

## 9. 公式

公式要求：

1. 原则上居中书写。
2. 若公式前有 `解`、`假定` 等文字，文字顶格，公式仍居中。
3. 公式末不加标点。
4. 公式序号按章编排，并在公式后靠页面右边线标注，如 `（1-1）`。
5. 文中引用公式时写 `见式（1-1）` 或 `由公式（1-1）`。
6. 公式较长时在等号或运算符处转行，转行时运算符写在转行式前，不重复书写。

OJPT 论文通常不需要复杂公式。若写通过率、时间复杂度或排序指标，可优先用文字和表格说明，必要时再使用公式。

## 10. 插表

表格要求：

1. 一般采用三线表。
2. 不加左、右边线。
3. 上、下底为粗实线 1 磅。
4. 中间线为细实线 0.75 磅。
5. 复杂表格可适当增加横线和竖线。
6. 表序按章编排，如 `表3-1`。
7. 表序与表名之间空一格。
8. 表名不使用标点符号。
9. 表题置于表上方，居中排写，黑体五号。
10. 表头应简单明了，尽量不用斜线。
11. 全表同一单位时，将单位符号移到表头右上角并加圆括号。
12. 表中数据必须正确无误，书写清楚。
13. 数字空缺处使用 `—`。
14. 表内文字和数字上下或左右相同时，不使用 `同上` 或引号代替。

表内字体：

| 内容 | 字体 |
| --- | --- |
| 中文 | 宋体五号 |
| 外文及数字 | Times New Roman 五号 |
| 普通表标题 | 中文黑体五号，数字及字母 Times New Roman |
| 统计表标题 | 黑体五号，单倍行距 |
| 补充材料 | 学校规范为宋体五号；学院模板补充说明曾提示楷体五号，最终按学校规范优先 |

OJPT 论文中的数据库表结构、接口清单、测试用例表均应按三线表整理。

## 11. 插图

插图要求：

1. 插图应符合国家标准及专业标准。
2. 插图应与文字紧密配合，文图相符，技术内容正确。
3. 图号按章编排，如 `图4-1`。
4. 图题由图号和图名组成。
5. 图题置于图下方。
6. 图注或其他说明置于图与图题之间。
7. 图名在图号后空一格。
8. 图题用黑体五号。
9. 引用图应说明出处，在图标题右上角加引用文献编号。
10. 有分图时，分图号用 `a)`、`b)` 标识并置于分图下。
11. 图中说明应使用中文或数字项号，外文引用图除外。
12. 插图与图题是整体，不得拆到两页。
13. 相关页剩余空间不足时，可将图移到下一页最前面。

学院模板补充说明：图片采用单倍行距，图名黑体五号、单倍行距、居中。

OJPT 论文应优先使用清晰的软件工程图，不应把系统截图替代所有设计图。截图适合放在实现和测试章节。

## 12. 代码

学院模板给出的代码格式要求：

1. 引出语可写 `该功能的核心代码如下。`
2. 代码整体首行空 2 格。
3. 单倍行距。
4. 英文和数字用 Times New Roman 五号。
5. 中文注释用宋体五号。
6. 代码前后适当空行。

OJPT 论文不建议放大段代码。正文应只展示关键逻辑片段，例如判题命令构造、JWT 校验流程、代码草稿保存逻辑。完整代码可不放或放附录。

## 13. 参考文献

参考文献要求：

1. 标题 `参考文献` 小二号黑体居中。
2. 著录按 GB/T 7714-2015《信息与文献 参考文献著录规则》执行。
3. 序号左顶格，用数字加方括号，如 `[1]`。
4. 文中引用序号格式应与参考文献一致。
5. 每条参考文献最后以句号结束。
6. 学院模板要求至少 15 篇。
7. 学院模板要求 80% 为近 5 年文献。
8. 学院模板要求英文文献不少于 3 篇。
9. 学院模板要求不能与开题报告中的参考文献重复。

常见类型格式：

| 类型 | 格式 |
| --- | --- |
| 专著 `[M]` | `[序号] 主要作者.文献题名[M].出版地:出版社,出版年:引文页码.` |
| 学位论文 `[D]` | `[序号] 作者.文献题名[D].单位所在地:署名单位,出版年.` |
| 期刊 `[J]` | `[序号] 主要作者.文献题名[J].刊名,年,卷（期）:起止页码.` |
| 报纸 `[N]` | `[序号] 作者.新闻[N].报纸名,出版日期（版次）.` |
| 会议 `[C]` | `[序号] 主要责任者.题名:其他题名信息[C].出版地:出版社,出版年.` |
| 专利 `[P]` | `[序号] 专利申请者或所有者.专利题名:专利号[P].公告日期或公开日期.` |
| 网上期刊 `[J/OL]` | `[序号] 作者.题目[J/OL].刊名,年,卷（期）:起止页码[引用日期].网址.` |
| 电子公告 `[EB/OL]` | `[序号] 作者.题目[EB/OL].发表日期/引用日期.网址.` |

按当前写作年份 2026 计算，近 5 年文献优先选择 2021-2026 年。OJPT 论文参考文献应覆盖在线判题系统、代码执行沙箱、Spring Boot、Vue、软件测试、Web 安全、教育信息化等方向。

## 14. 致谢与附录

致谢为可选项，但模板和参考论文均保留。致谢应表达对指导老师、学院老师、同学朋友、家人的感谢，避免过度口语化和夸张表达。

附录为可选项，不宜放在正文中但有重要参考价值的内容可放入附录，例如：

1. 公式推导。
2. 程序流程图。
3. 图纸。
4. 数据表格。
5. 重要代码片段。
6. 补充测试记录。

附录格式：

1. 附录另起一页。
2. 附录序号采用 `附录1`、`附录2`。
3. 用四号黑体字左起顶格。
4. 标题后不加标点。
5. 空一行书写附录内容。
6. 附录内容字体字号参照正文要求。

## 15. 参考论文结构观察

参考论文《基于SpringBoot的温室大棚环境监测与预警系统设计论文》是软件工程类系统设计实现论文，观察到：

1. 总页数约 95 页。
2. 正文主线为 7 章。
3. 图数量较多，包含功能模块图、数据流图、总体架构图、实体属性图、E-R 图、系统流程图和大量页面截图。
4. 表数量较多，包含数据源表、数据流表、数据存储表、数据加工表、数据库表和测试结果表。
5. 第 6 章重点用页面截图说明功能测试流程。
6. 参考文献约 20 篇，年份集中在近年。

参考论文目录结构：

1. 绪论：前言、选题背景、选题目的、选题意义。
2. 相关技术和理论概述。
3. 系统需求分析：系统功能分析、系统功能流程介绍、数据流分析、数据字典。
4. 系统分析与设计：总体架构设计、数据库设计、概念结构设计、关系模型、数据库表。
5. 系统的开发设计与实现：按功能模块逐项展开。
6. 系统功能测试：测试方法、测试环境、功能测试、测试结果。
7. 结论。

OJPT 论文可借鉴该结构，但应把农业系统内容替换为在线编程训练平台，不写与当前项目无关的温室大棚、学校班级或历史模型功能。
