## 三、拟调整后的论文结构

- 删除摘要前中文论文题目。
- 删除 Abstract 前英文论文题目。
- 中文摘要保留 3 段：
  - 第 1 段：在线判题平台背景、人工评阅痛点、系统建设目的。
  - 第 2 段：系统技术框架，包括 SpringBoot、Vue 3、MySQL、Redis、Docker、JWT 等。

处理原则：

- 删除“用户角色分析”这一章节，不再按普通用户、管理员角色分别铺开。
- 功能需求直接按系统功能介绍，如账号认证、题库浏览、在线做题、代码运行、提交判题、提交记录、训练看板、后台题目管理、后台用户管理、判题环境检测等。
- “系统功能模块图”保留在 3.1.2。
