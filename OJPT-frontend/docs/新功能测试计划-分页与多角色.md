## 四、Browser Tab 自动化建议（Cursor Agent）

在 Composer 中可让 Agent 按下面顺序执行（账户密码同上）：

1. **打开并登录**  
   - 打开 http://localhost:5173，点击登录，填写 `admin@qq.com` / `123456`，提交。
2. **管理员分页**  
   - 进入管理 → 用户管理，检查分页条并翻页或改每页条数；进入学校管理，同样检查。
3. **校方分页**  
   - 退出，登录 `test_school@qq.com` / `123456`，进入校方管理，依次切院系/班级/教师/学员 Tab，每处检查分页条与翻页。
4. **教师分页**  
   - 退出，登录 `test_teacher@qq.com`，进入教师后台，检查班级列表分页，再点某班级的学员管理、申请审核、教师管理，各检查分页。
5. **学员分页**  
   - 退出，登录 `test_user@qq.com`，进入学员中心，检查我的班级分页，再点「查看成员」检查弹窗内分页。

## 五、通过/失败标准

- **通过**：各角色对应列表页均出现分页条，翻页或修改每页条数后列表数据更新，无报错；可选：Network 中请求带 `page`/`size`，响应为 `records` + `total` 等。
- **失败**：列表无分页条、翻页无反应、控制台或 Network 报错、数据错乱。
